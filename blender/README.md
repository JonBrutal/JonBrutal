# YandexGIS — аналог BlenderGIS с Яндекс Картами

Аддон для Blender: скачивает подложку из Яндекс Карт (схема, спутник, гибрид),
кладёт её в сцену в правильном масштабе и с привязкой к координатам, добавляет рельеф
и здания из OpenStreetMap.

Работает в Blender 3.6 – 5.x. Проверен на Blender 5.0.

## Чем отличается от BlenderGIS

* **Правильная проекция Яндекса.** Тайлы Яндекса нарезаны в эллипсоидальном Меркаторе
  (EPSG:3395), а у OSM, Google и BlenderGIS — сферический (EPSG:3857). Если просто
  подставить URL Яндекса в BlenderGIS, картинка съедет по вертикали: на широте Москвы
  примерно на 35 км. Здесь пересчёт встроен, и подложки Яндекса, OSM и рельеф
  совпадают друг с другом.
* **Настоящие метры в сцене.** Координаты сцены — поперечный Меркатор с центром в точке
  привязки, поэтому 1 единица Blender = 1 метр на местности. В веб-Меркаторе BlenderGIS
  на широте Москвы всё растянуто примерно в 1,8 раза.
* **Место задаётся ссылкой.** Найдите место в браузере на yandex.ru/maps, скопируйте
  ссылку и нажмите «Из ссылки». Ещё можно искать по адресу или вводить координаты.

## Установка

```bash
python3 blender/build.py      # → blender/dist/yandex_gis-0.1.0.zip
```

* **Blender 4.2 и новее:** Edit → Preferences → Get Extensions → ⌄ → *Install from Disk…* → zip.
  Включите *Preferences → System → Network → Allow Online Access*, без этого аддон
  не может ничего скачать.
* **Blender 3.6 – 4.1:** Edit → Preferences → Add-ons → *Install…* → zip, затем поставьте галочку.

Панель: 3D-вьюпорт → боковая панель (N) → вкладка **YandexGIS**.

## Как пользоваться

1. **Место.** Задайте точку одним из способов:
   * вставьте ссылку Яндекс Карт в поле со значком ссылки и нажмите кнопку справа
     (если поле пустое, ссылка берётся из буфера обмена). Зум подтянется из ссылки;
   * поиск по адресу. Если в настройках указан ключ Геокодера Яндекса, ищет Яндекс,
     иначе Nominatim (OSM);
   * введите широту и долготу. Строку «55.753960, 37.620393», как её копирует Яндекс,
     тоже можно вставить в поле ссылки.

   «Открыть в Яндекс Картах» открывает текущую точку в браузере. Там удобно
   найти нужное место и скопировать ссылку обратно.
2. **Область.** «Вокруг точки»: прямоугольник заданной ширины и высоты в метрах.
   «По объекту»: габариты активного объекта, например уже загруженной подложки.
3. **Подложка.** Выберите слой и зум и нажмите «Загрузить подложку». Получится плоскость
   с материалом и текстурой. Если включить «С рельефом», плоскость сразу получит высоты.
   Если текстура больше лимита из настроек (по умолчанию 8192 px), зум понижается
   автоматически.
4. **Рельеф и здания.**
   * «Положить на рельеф» опускает вершины выбранных мешей на поверхность земли.
     Подходит для дорог, участков и любых своих объектов.
   * «Здания OSM» выдавливает контуры по тегам `height` / `building:levels` / `min_height`.
     Если этажность не указана, берётся «Этажей по умолчанию».

При первой загрузке сцена привязывается к точке: эта точка становится началом
координат (0, 0, 0). Все следующие подложки и здания встают относительно неё.
Высоты абсолютные, в метрах над уровнем моря.

Текстуры сохраняются в папку `yandexgis/` рядом с .blend, если файл уже сохранён.
Если нет, они упаковываются внутрь .blend.

## Слои

| Слой            | Источник                               | Проекция  | Макс. зум |
|-----------------|----------------------------------------|-----------|-----------|
| Яндекс Схема    | core-renderer-tiles.maps.yandex.net    | EPSG:3395 | 21        |
| Яндекс Спутник  | core-sat.maps.yandex.net               | EPSG:3395 | 20        |
| Яндекс Гибрид   | спутник + слой подписей `skl`          | EPSG:3395 | 20        |
| OpenStreetMap   | tile.openstreetmap.org                 | EPSG:3857 | 19        |
| Свой источник   | шаблон URL из настроек аддона          | любая из двух | —     |
| Рельеф          | AWS Terrain Tiles (Terrarium, SRTM)    | EPSG:3857 | 15        |

Если Яндекс поменяет адреса тайлов, в настройках аддона можно задать свой шаблон
(`{x} {y} {z} {scale} {lang} {s}`) и отметить «Эллипсоидальный Меркатор».

## Настройки аддона

Папка кэша, язык подписей на схеме, схема в 2× разрешении (тайлы 512 px), число потоков,
лимит размера текстуры, User-Agent, ключ Геокодера Яндекса, свой источник тайлов.

## Ограничения

* В отличие от BlenderGIS, здесь нет интерактивной карты внутри вьюпорта. Место выбирается
  в браузере и передаётся ссылкой.
* У зданий-мультиполигонов пропускаются внутренние дворы. Крыши плоские.
* Рельеф построен по SRTM с разрешением около 30 м. Для детальной застройки его хватает
  только как общей формы местности.
* Адреса тайлов Яндекса неофициальные (их использует сам сайт yandex.ru/maps) и могут
  поменяться. Перед использованием проверьте
  [условия использования Яндекс Карт](https://yandex.ru/legal/maps_termsofuse/): для
  коммерческих проектов Яндекс требует работать через официальные API с ключом.

## Тесты

```bash
python3 -m unittest discover blender/tests
```

Тесты проверяют проекции, разбор ссылок и разбор данных OSM. Эталонные значения
проекций посчитаны в PROJ.
